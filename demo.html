煽り注意報を体験する

このページは体験モードです。下の投稿と記事は見本で、判定結果はあらかじめ本物の Jev で判定しておいたものです。 API キーも通信も不要で、費用もかかりません。

1. タイムラインや検索結果では（ブロックごと）

手口が見つかった投稿の右上にだけ 「手口」の印が付きます。印を押してみてください。どんな手口か、どう向き合えばよいかが出ます。 暗いニュースや、はっきりした反対意見には付きません。見ているのは書き方で、どの立場の主張かではないからです。

    2. 記事ページでは（ページ全体）

    ページ1枚をまとめて判定し、画面の隅に結果を出します。記事ページでは「数字・研究の出どころがあいまい」も見ます （研究や統計の数字が、元の情報源から切り離されて使われていないか）。

    3. しくみ

    Jev は、文章が判定基準に当てはまりそうかどうかを、確率で返すことに特化した AI です。 文章を書いたり要約したりはせず「当てはまる確率」だけを返すので、軽く、安く、速く動きます。 煽り注意報は、その確率が感度（閾値）を超えたときだけ「手口」の印を出します。

    本番モードでは、判定した分だけ料金がかかります。調べた範囲では（2026年9月時点）、Jev を無料で使える枠はありません。 ただし料金はとても安く、1件あたり約 0.004 円です。1日300件を判定しても、ひと月30円ほどです。 最初に少額をチャージしておけば、かなりの時間と量を扱えます。流し読みした投稿は判定しないので、実際はさらに少なく済みます。

    4. 「手口」の印の読み方

    • … いちばん確率の高い手口の名前です。「ほか1」は、ほかにも当たった手口の数です。確率は、印を押して「詳しく」を開くと出ます（印に % を出すと「95% うそ」のように読まれやすいためです）。
    • 印は「悪い投稿」「うそ」という判定ではありません。「この手口が使われている」という知らせです。どう受け取るかは、あなたが決めてください。
    • 手口｜誘導の決まり文句 … 「プロフのリンクから」「公式LINE登録」「今だけ」のような、リンクや登録へ誘導する決まった言い回しです。これは Jev ではなく決まった言い回しの一覧で見つけているので、API キーがなくても動きます。
    • Jev は内容の真偽を確かめていません。どのくらいで印を付けるか（感度）は、設定画面の「高度な設定」で変えられます。

    5. 体験モードと本番の違い

    体験モード（このページ）本番
    判定するもの用意した見本の投稿と記事だけあなたが開いたサイトの投稿や記事
    判定のしかたあらかじめ判定した結果を表示するだけその場で Jev に判定させる（1件 0.3 秒ほど）
    API キー不要Jev の判定には必要（TypeSafe または Vercel で発行）。キーがなくても「誘導の決まり文句」だけは本番のサイトで動きます
    通信なし判定する本文を接続先に送る（あなたが選んだサイトのものだけ）
    費用なし判定した分だけ（無料枠なし）。1件あたり約 0.004 円（概算）。流し読みした投稿は判定しない
    感度などの設定今の設定で表示同じ設定で判定

    6. 本番を始めるには

    1. 設定画面で API キーを入れ、「接続テスト」を押します。
    2. 判定したいサイトを開き、拡張機能のアイコンから「ページ全体」か「ブロックごと」を選びます。

    費用の概算は、1回の判定で約 600 トークンを送るとして、入力 100 万トークンあたり $0.042・1 ドル 150 円で計算しています。
