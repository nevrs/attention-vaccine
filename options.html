煽り注意報の設定

ネットには、読む人の怒りや不安を反射的に引き出して、クリックや拡散、購入につなげる書き方があふれています。
煽り注意報は、そうした「手口」が使われている投稿や記事に ‼️ を付けて知らせます。
見ているのは書き方だけです。どの立場の主張か、内容が正しいかどうかは判定しません。 手口に気づいたうえでどう受け取るかは、あなたが決めてください。判定基準も自分で設定できます。

まず体験してみる（キー不要・費用なし）→

判定には TypeSafe 社の AI「Jev」を使います。Jev は文章を読んで「この手口が使われているか」を確率で答えるだけの小さな AI で、 文章を書いたり要約したりはしません。

接続先と API キー

使う人それぞれが自分のキーを入れます。料金はキーの持ち主に請求されます（入力100万トークンあたり $0.042）。

キーはこのブラウザの中だけに保存します（同期しません。送る先は接続先だけ）。

使い方

  1. 上の欄に API キーを入れます。
  2. 判定したいサイトを開き、拡張機能のアイコンから選びます。初めて選ぶサイトでは、Chrome が「このサイトのデータの読み取り」の許可を確かめます。許可したサイトでしか動きません。
    • ページ全体: 記事ページ向け。ページ1枚を判定し、画面の隅に結果を出します。
    • ブロックごと: タイムラインや検索結果向け。1件ずつ判定します。
  3. 手口が見つかった所にだけ ‼️ が付きます。押すと、手口の名前・理由・数値が出ます。本文は隠しません。

画面に少しとどまった投稿だけを判定します。流し読みした投稿は判定しないので、軽く、その分の費用もかかりません。
判定のために接続先へ送るのは、あなたが選んだサイトの本文だけです。

許可が必要なサイトがあります
v0.17 から、拡張が動くのは許可したサイトだけになりました。次のサイトはモードを選んであるのに許可がないので、今は判定していません:

見つける手口

Jev は真偽を確かめません。見ているのは書き方です（どうあおっているか、何に誘導しているか、根拠を示しているか）。
‼️ は「悪い投稿」という判定ではなく、「この手口が使われている」という知らせです。

感度（閾値）

Jev の確率がこの値以上で ‼️ を付けます。下げるほど多く付き、上げるほど確かなものだけに付きます。初期値は少数の例文で決めた仮の値です。

判定しないアカウント（除外リスト）

ここに書いたアカウントの投稿は判定しません（接続先にも送りません）。1行に1つ書きます（先頭の @ はあってもなくても構いません）。 投稿者を読み取れるサイト（X・Bluesky）でだけ使えます。ページ全体モードでは、ページの最初の投稿の投稿者で決めます。

この道具の本来の価値は、誰が書いたかではなく、書き方だけを見ることにあります。 信頼している人も手口を使うことがあり、除外すると、それには気づけなくなります。

高度な設定

判定までの待ち時間

ブロックごとモードで、投稿が画面に見えてから判定を始めるまでの秒数です。長いほど軽く（流し読みした投稿を判定しない）、短いほど早く ‼️ が出ます。

1日の判定回数の上限

接続先への問い合わせを1日にこの回数までに抑えます（料金の使いすぎを防ぐため）。超えるとその日は判定を止めます。料金の目安: TypeSafe は入力 100 万トークンで $0.042、1回は数百トークンです。

デバッグ

見つけた「1件分」を点線（判定済みは緑の実線）で囲み、当たらない件にも控えめな「読んだ」を付けます（押すと数値）。 画面の隅の表示に、区切りの出どころ・件数・最後のエラーを出し、開発者ツールのコンソールに [Jev] の記録（本文の冒頭40字と数値）を出します。 感度の調整や、動かないときの原因探しに使ってください。

ほかの判定項目

自分で足す項目

問いの書き方や閾値を、ChatGPT などの AI と相談しながら直せます。下のボタンで、拡張のしくみと今の項目をまとめた文を出すので、コピーして AI に貼ってください。 特定の投稿について相談するときは、その投稿の ‼️ の詳細にある「この判定を AI に相談する」から。AI の案が効くかどうかは、Jev で測るまで分かりません。

一次ソースと比較

ページ全体モードで、記事に論文のリンク（DOI・arXiv）があるときだけ動きます。 論文の DOI を無料の論文データベース OpenAlex に問い合わせて要旨を取り、記事と並べて Jev に1回だけ判定させます。
比べられるのは要旨だけです。要旨にない数字や、数字の細かいずれは確かめられません。

サイト別の設定

ふつうはページ上でクリックして作ります（拡張のアイコン →「表示がずれるとき」）。 ここでは、作った設定の確認・修正・削除と、他の人との共有ができます。組み込みのおすすめ設定より優先します。
1件分: ブロックごとモードの区切り。本文: 1件の中で Jev に渡す部分。判定範囲: ページ全体モードで判定する部分。 どれも CSS セレクタで、空欄なら組み込みの設定か自動検出を使います。

書き出し・読み込み（共有用）

「書き出し」で下の欄にサイト別の設定が出ます。コピーして他の人に渡せます。 受け取った設定を貼って「読み込み」を押すと、今の一覧に追加されます（同じサイトは上書き）。保存を押すまで確定しません。 API キーは含まれません。
